Guide de démarrage

Comment utiliser la plateforme ?

Suivez ces étapes pour créer votre compte et commencer

1
🛡️

L'Administrateur crée son compte

Sur l'écran de connexion, sélectionnez Administrateur, saisissez votre email, votre nom et votre mot de passe.

①Cliquez sur "🛡️ Administrateur"
②Saisissez votre email et votre mot de passe
③Cliquez "Se connecter / Créer mon compte →"
✅ Si l'email est nouveau, remplissez votre nom pour créer votre espace admin.
↓
2
👥

L'Admin crée un compte Fonctionnaire

Une fois connecté, allez dans Fonctionnaires et ajoutez un membre. Un code d'invitation est généré automatiquement.

①Menu gauche → "👥 Fonctionnaires"
②Cliquez "＋ Ajouter un fonctionnaire"
③Remplissez : nom, email, téléphone, département
④Copiez le code d'invitation et transmettez-le
🔑 Un code unique (ex: AB3D7FKZ) est généré. Transmettez-le au fonctionnaire par email ou message.
↓
3
👨‍💼

Le Fonctionnaire active son compte

Le fonctionnaire se connecte avec son email et le code reçu, puis crée son mot de passe personnel.

①Cliquez sur "👨‍💼 Fonctionnaire"
②Saisissez son email et le code d'invitation
③Crée son mot de passe → Compte activé !
🎯 Le fonctionnaire accède à ses missions, peut en réserver, les démarrer et les marquer terminées.

📖 Guide d'utilisation

Tout ce que vous devez savoir

1

Créer votre compte administrateur

Sur la page de connexion, cliquez "🛡️ Administrateur", entrez votre email et mot de passe. Si l'email est inconnu, remplissez votre nom pour créer votre espace.

2

Ajouter des fonctionnaires

Menu "👥 Fonctionnaires" → "＋ Ajouter". Un code d'invitation unique est généré — transmettez-le au fonctionnaire.

💡 Vous pouvez régénérer le code via le bouton 🔑 sur la fiche du fonctionnaire.
3

Créer des missions

Cliquez "＋ Créer une mission". 3 modes disponibles :

📋 Ouverte

Tout fonctionnaire peut la prendre

🎯 Ciblée

Assignée à un fonctionnaire précis

🌐 Pool

Premier arrivé, premier servi

4

Valider les missions terminées

Quand un fonctionnaire marque une mission terminée, elle passe en "À valider". L'admin peut ✅ Valider ou ↩ Rejeter.

🔔 Un badge rouge apparaît dans le menu quand des missions attendent votre validation.
5

Suivre les statistiques

Menu "📊 Statistiques" → tableau de bord avec missions, fonctionnaires actifs, urgences et classement.

1

Activer votre compte

Votre admin vous a transmis un code d'invitation. Sur la connexion : "👨‍💼 Fonctionnaire" → email → le système vous demandera votre code puis de créer votre mot de passe.

💡 Le code ressemble à : AB3D7FKZ
2

Consulter les missions

Dans "📋 Missions", vous voyez toutes les missions de votre domaine, filtrables par statut.

3

Prendre en charge une mission

📋 Ouverte

Cliquez "▶️ Prendre en charge"

🌐 Pool

Cliquez "⚡ Réserver"

🎯 Ciblée

Assignée directement

4

Avancer et terminer

Cliquez "▶️ Démarrer" puis "✔ Marquer terminée". L'admin reçoit une demande de validation.

⏳ La mission passe en "À valider" jusqu'à confirmation.
5

Suivre votre activité

Menu "👤 Mon profil" → statistiques personnelles et historique.
